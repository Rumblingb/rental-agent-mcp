# Contributing

## How to contribute

1. Fork the repo
2. Create a feature branch: `git checkout -b feat/my-feature`
3. Make your changes
4. Run tests: `python3 -m pytest tests/`
5. Submit a PR

## Guidelines

- Keep zero-dependency where possible
- All tools must work without API keys
- Add tests for new calculations
- Update docs for new features
- Use type hints
